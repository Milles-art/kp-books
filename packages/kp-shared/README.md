# @Milles-art/kp-shared

Shared KP frontend layer (Icon, Footer, BookCover, api, money, tokens) used by KP Books and KP Wear.

## Consuming
Add to your app: `"@Milles-art/kp-shared": "file:../packages/kp-shared"` (or publish to npm).
Import: `import { Icon, Footer, money } from '@Milles-art/kp-shared';`
Import tokens: `import '@Milles-art/kp-shared/styles/tokens.css';`
